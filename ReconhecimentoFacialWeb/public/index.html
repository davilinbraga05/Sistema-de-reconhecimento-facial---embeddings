Demonstração Acadêmica

O que é um Embedding Facial?

O modelo FaceRecognitionNet recebe a imagem alinhada pelos 68 marcos anatômicos da face e gera um vetor contínuo de 128 números de ponto flutuante:

V = [v₀, v₁, v₂, ..., v₁₂₇] ∈ ℝ¹²⁸

Rostos da mesma pessoa mapeiam para coordenadas próximas no espaço 128-dimensional, enquanto rostos diferentes são projetados para distâncias maiores.

Métrica de Decisão (Distância Euclidiana)

A distância entre o vetor capturado A e a amostra cadastrada B é calculada por:

d(A, B) = √( ∑ᵢ₌₀¹²⁷ (A[i] - B[i])² )

Regra de Decisão: Se d(A, B) ≤ Threshold e a margem contra o segundo colocado for suficiente, o acesso é LIBERADO; caso contrário, é NEGADO.

Parâmetros de Classificação Biométrica

Ajuste os limiares matemáticos do motor de decisão euclidiano.

0.550
0.25 (Mais Rigoroso) 0.55 (Padrão Recomendado) 0.95 (Mais Tolerante)

Distância euclidiana máxima permitida entre o vetor capturado e o perfil cadastrado. Valores menores reduzem drasticamente falsos positivos, enquanto valores maiores facilitam o reconhecimento sob iluminação variável.

0.050
0.01 (Tolerante) 0.05 (Equilibrado) 0.20 (Separação Rígida)

Separação mínima exigida entre o melhor candidato (1º colocado) e o segundo mais próximo (2º colocado). Se a diferença for menor que este valor, a decisão é classificada como ambígua e o acesso é negado por segurança.

Privacidade e Limitações Biométricas

Aviso Importante: Ataques de Apresentação (Spoofing)

Este sistema opera com webcam convencional 2D sem sensores de profundidade (IR / LiDAR) ou algoritmo de vivacidade ativa (liveness). Portanto, uma fotografia ou tela de celular pode enganar o modelo. Este software destina-se a fins estritamente acadêmicos e educacionais e NÃO DEVE ser utilizado para acionamento de portas, catracas ou instalações físicas de alta segurança.

Tratamento de Dados Biométricos Sensíveis

  • Sem armazenamento de fotos: O banco de dados SQLite armazena apenas vetores abstratos de 128 dimensões. Nenhuma imagem real ou vídeo é mantido em disco.
  • Localhost restrito: A aplicação e as APIs escutam unicamente na interface de loopback local (127.0.0.1:3000).
  • Direito ao esquecimento: Ao excluir um usuário na aba de gerenciamento, todos os seus vetores de embedding são imediatamente apagados em cascata.
